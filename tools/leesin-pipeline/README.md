# Lee Sin pipeline

Assets oficiales (Khada GLB + CommunityDragon particles + DDragon HUD/splash).

```bash
npm run leesin:setup
```

Por pasos:

```bash
npm run leesin:download          # Khada skin0 GLB
npm run leesin:download-spells   # particles + spell icons
npm run leesin:download-splash   # splash.jpg + loadscreen
npm run leesin:render            # spritesheet_authentic_hd.png
```

Jugar en dev: `?champion=leesin`
