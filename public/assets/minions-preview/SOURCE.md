# Minions preview — procedencia

## Modo Riot (default en `/minion-preview.html`)

Iconos **square** del HUD del cliente (`*_square.png`, **128×128**), extraídos vía CommunityDragon.

```bash
npm run minions:download-riot-hud
```

→ `public/assets/minions-preview/riot-square/*.png`

- **Propiedad:** Riot Games, Inc. — uso fan / for fun en este prototipo.
- Son **retratos** (como el icono en la barra de LoL), no sprites top-down bakeados.

## Modo Inspired

Bake procedural en `src/minionPreview/inspiredMinionTextures.ts` — arte del repo.

## Atlases 3D (galería HTML)

Diffuse ~512² desde CDN — referencia para pipeline GLB→spritesheet.

Documentación: `tools/minions/minion-assets-research.md`
